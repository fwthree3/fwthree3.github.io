**2025–2026**

I worked on real-time motion planning and control for the dual arms of a humanoid robot, covering the full autonomy stack from low-level real-time control to high-level task execution.

**Contributions**
- A Jacobian-based custom solver for real-time position/velocity servoing of both arms, including testing and debugging
- MoveIt-based path planning (time-parameterized trajectories) and control logic
- A custom multi-axis EtherCAT ROS2 slave driver plugin (URDF-based); core maintainer of the team's ROS2 repository
- An autonomous pick-and-place framework, including off-the-shelf YOLO-based object recognition
- Core contributor to public demos, including Discovery X 2026 and a CTV News segment
