**Robot Hardware Researcher**

For a 6-axis serial manipulator used in bone-aligning surgical robots, I developed the motion planning algorithm and execution program for arbitrary linear end-effector trajectories, with and without end-effector rotation.

**Contributions**
- Motion planning algorithm for arbitrary linear motions of the end-effector, built on given forward/inverse kinematics resources
- Output design compatible with Solidworks simulation for verification
- Generation of the execution file package

**Tools**: MATLAB
